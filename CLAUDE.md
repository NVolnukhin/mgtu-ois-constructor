# Конструктор экспертных систем

Конструктор на React и TypeScript без бэкенда: база знаний настраивается в браузере, хранится в localStorage и передаётся файлом JSON. Вырос из прототипа ДЗ 2-1 по «Основам интеллектуальных систем» (зачтён, репозиторий `../mgtu-ois`, его не трогаем).

Начинай с [docs/constructor-spec.md](docs/constructor-spec.md): там решения автора, предположения, формат базы и порядок работы. Как устроен вывод — [docs/methodology.md](docs/methodology.md), дизайн-система — [DESIGN.md](DESIGN.md).

## Команды

- `npm run dev` — разработка; порт 5173 занят чужим процессом, используй `--port 5190 --strictPort`.
- `npm run build` — типы и сборка. Посмотреть сборку как на Pages: `npm run preview -- --port 5191 --strictPort --base /mgtu-ois-constructor/`.
- `npm run check` — проверка базы знаний, требований и картинок.
- `npm run docs` — пересобрать сгенерированную часть `docs/` после правок в `content/`.

## Договорённости

- Коммиты делает Claude. Пушить только по явной просьбе: пуш в `main` сразу деплоит сайт.
- Если есть развилка, которая влияет на поведение, сначала спросить автора.
- Тексты интерфейса, документация и комментарии в коде — на русском.
- База знаний содержит правила двух видов: «параметр + атрибут» (вариант ответа и его веса, А1, А2, …) и «параметр + параметр» (П1, П2, …). Не называть первые просто «весами» или «связями»: на этом уже споткнулись на защите.
- Числа о базе знаний в текстах берутся из данных, а не пишутся руками.
- В репозитории нет упоминаний исходного проекта, из которого когда-то выросли вопросы: ни в файлах, ни в сообщениях коммитов. Старые выгрузки сюда не копируются.
- Ключи localStorage начинаются с `mgtu-ois-constructor/`: на github.io у сайтов аккаунта общий origin.
- Утилиты `gh` на машине нет. Статус деплоя смотри через `https://api.github.com/repos/NVolnukhin/mgtu-ois-constructor/actions/runs`.
