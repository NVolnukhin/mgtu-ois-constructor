# Конструктор экспертных систем

Человек собирает в браузере экспертную систему на любую тему: атрибуты, объекты, вопросы, правила и картинки. База хранится в localStorage, а другому человеку передаётся файлом JSON. Бэкенда нет.

Сайт: https://nvolnukhin.github.io/mgtu-ois-constructor/

## Что умеет

- **Главный экран.** Мои базы, «Создать», «Импорт JSON» и встроенный пример.
- **Импорт и экспорт.** Файл JSON открывается в любом браузере. Присланная база сразу открывается как тест, редактор — по кнопке.
- **Тест.** Вопросы с одним или несколькими ответами и рейтинг объектов, который пересчитывается после каждого ответа. В конце весь рейтинг, объяснение и итог по группам, если они заданы.
- **База знаний и рабочая БД.** Всё содержимое базы и факты текущего сеанса можно посмотреть.
- **Редактор.** Атрибуты, группы, объекты, вопросы, правила «параметр + атрибут» (вариант ответа и его веса) и «параметр + параметр» (условия через И, цепочки работают), настройки, картинки по URL. Изменения сохраняются сразу.
- **Проверка.** Ошибки в базе, требования ДЗ 2-1, тестовые профили.

## Пример

«Определение волонтерской направленности личности» — ДЗ 2-1 «Разработка прототипа экспертной системы» по ОИС, МГТУ им. Н.Э. Баумана. Выполнил Волнухин Никита, СГН3-72Б. Сданная версия лежит в репозитории [mgtu-ois](https://github.com/NVolnukhin/mgtu-ois).

Система задаёт вопросы о предпочтениях, возможностях и склонностях. После каждого ответа она ранжирует виды волонтёрской деятельности, а в конце называет направленность и объясняет, почему она подходит. Как пример выполняет требования задания и что показывают его тестовые профили — в [`docs/validation.md`](docs/validation.md). Эти таблицы собираются из данных, а `npm run check` следит, чтобы результаты не разошлись со сданной версией.

## Команды

Нужен Node.js 22.18 или новее: скрипты написаны на TypeScript и запускаются без сборки.

```bash
npm install
```

```bash
npm run dev
```

Запускает сайт локально с автообновлением.

```bash
npm run build
```

Проверяет типы и собирает сайт в `dist/`. Посмотреть сборку — `npm run preview`.

```bash
npm run check
```

Проверяет пример: структуру, требования задания, картинки, тестовые профили, случайные анкеты и совпадение со сданной версией. Прогоняет тесты движка и редактора на придуманных базах. Если что-то не так, завершается с ошибкой.

```bash
npm run docs
```

Пересобирает `docs/knowledge-base.md`, `docs/objects.csv`, `docs/questions.csv`, `docs/validation.md` и `docs/credits.md` после правок в `content/`.

## Деплой на GitHub Pages

Сайт собирает и выкладывает workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) при каждом пуше в `main`: он ставит зависимости, запускает `npm run check` и `npm run build`. Перед первым пушем Pages нужно один раз включить: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Пути в сборке относительные (`base: './'` в `vite.config.ts`), а экраны различаются адресом после `#`, поэтому сайт работает и из подпапки Pages, и из любой другой.
